# XXD Panel 043｜深色平面真实皂沫生产提示词

## 运行时完整画布契约（最高优先级）

- `TOP_BOTTOM` 与 `LEFT_RIGHT` 默认把当前原图作为高保真编辑／参考输入，用本提示词一次生成一张完整成品；不要预先拆成摄影半幅和设计半幅。
- 上下模式在整张成品中保留上方约 50% 的高保真原图，在下方完成本风格转译；左右模式对应左侧约 50% 原图与右侧风格转译。两区要在色彩、光线、节奏、文字与含义上形成一体化设计。
- `DESIGN_ONLY` 与 `WALLPAPER_PACK` 使用完整画布，原图只作身份与内容依据而不显示。壁纸仍按设备分别重新构图。
- `FINAL CANVAS` 指整张最终成品比例／像素，必须由用户在生成前明确；不得静默采用源图尺寸。`DESIGN FRAME` 只在完整画布重试失败并触发确定性拼合兜底时使用。
- 完整画布失败时只针对失败条件重试一次；仍失败、用户要求原片逐像素不变、当前通道无法实现目标画幅，或需要无创像素校准时，才允许脚本拼合。

只处理当前新任务明确提供的这一张源照片。私下锁定身份、结构、姿态、方向、动作、功能、开口、关系、情绪含义与源图色彩，至少保留三个源图专属线索；不得借用其他输入、旧输出或样张。

## 审美重构

让主体以真实白色皂沫、细密气泡、透明泡膜、湿润边缘、破泡缺口与皂液残留直接形成于深色平面，只保留决定性轮廓、比例、动作和结构转折，并以正面无畸变摄影呈现。

严格遵循这条因果链：锁定决定性轮廓与动作 → 保留三个线索 → 用泡沫密度、缺口、泡膜与残留转译实体 → 选择一个与源图隐性关联的深净底色 → 正面无透视畸变拍摄 → 只留少量散泡与水痕 → 让文案像原本就存在于平面上的标记。

## 硬性视觉要求

- 从外轮廓、比例、姿态、方向、动作、开口或结构转折中保留至少三个源图专属线索。
- 使用真实白、乳白和半透明皂沫，包含大小变化的细密气泡、泡膜、湿边、破泡空洞、聚散、变薄与少量皂液残留。
- 采用完全正面、平视、平面摄影视角，水平垂直准确，无广角、倾斜、纵深夸张或边缘变形。
- 选择从源图色相与温度衍生或协调的深、净、低反射、略湿平整底面，保持克制而明确的明暗对比。
- 主体周围只允许少量散泡、水珠、接缝与湿痕，并保留大面积安静空间。

## 文案与语言

服从已经确认的自动文案、准确自定义文案或无文字模式，以及目标语言／地区。使用一个极短主体、动作、情绪或隐喻标题，最多配两个状态词；目标语言文字沿轮廓、平面轴线、泡沫边缘或负形排列，可被泡沫局部遮挡，但必须可读且像存在于底面。 用户准确文案逐字保留；无文字模式不得出现字母、字符、数字、标题、标签或伪文字。

## 模式与验收


拒绝：3D泡沫雕塑、立体泡沫模型、奶油、棉花、云朵、塑料泡泡、CG材质、斜视镜头、透视夸张、浅色低对比底、浴室广告、卡通气泡、密集飞溅装饰与模板平铺。同时拒绝 logo、水印、色卡、UI、设备样机、无依据事实、伪外语和不可读文案。

任何硬性条件失败都必须纠正位图资产，不得以程序绘图、SVG、HTML、Canvas、3D 代码或后期文字覆盖伪造成品。
